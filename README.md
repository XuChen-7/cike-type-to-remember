# Word.html

**打出来，记得住。**

Word.html 是一款在 Mac 本地使用的打字记忆工具，把需要掌握的单词、术语或概念整理成自己的练习库，再通过连续输入和释义默写反复巩固。

![Word.html 预览](public/og.png)

## 主要功能

- 按科目和自定义文件夹管理词条。
- 批量导入“词汇/概念 + 释义”内容，支持编辑和批量删除。
- 连续打字练习，词条随机排列并可无限循环。
- 释义默写模式，空格和标点均会清楚显示并按位置输入。
- 支持回车提交和进入下一题。
- 显示正确率、平均速度和进步趋势。
- 无需账号，词库和练习记录只保存在自己的 Mac 上。

## 安装与升级

从 [Releases](../../releases) 下载 Apple 芯片版 ZIP，解压后运行“安装 Word.html.command”。安装完成后，桌面会出现“Word.html”网页快捷入口。

同一个 ZIP 同时用于全新安装和升级。再次运行新版安装程序时，只更新网页内容和功能；已有科目、文件夹、词条、封面和练习记录不会被覆盖，升级前还会自动备份。

> 支持 M1、M2、M3、M4、M5 全系 Apple Silicon Mac，包括 Pro、Max 和 Ultra 机型。首次被 macOS 拦截时，请右键安装程序并选择“打开”；无需关闭系统安全保护。
