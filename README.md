# 词刻

词刻是一款在 Mac 本地使用的打字背词工具，将词汇记忆和连续打字练习结合起来。

![词刻预览](public/og.png)

## 主要功能

- 按科目和自定义文件夹管理词条。
- 批量导入“词汇 + 释义/概念”内容，支持编辑和批量删除。
- 连续打字练习，词条随机排列并可无限循环。
- 释义默写模式，根据提示拼写完整词条。
- 显示正确率、平均速度和进步趋势。
- 无需账号，词库只保存在自己的 Mac 上。

## 安装与升级

从 [Releases](../../releases) 下载最新的 Apple 芯片版 ZIP，解压后打开“安装词刻.app”。安装器会自动创建桌面快捷入口。

升级时直接运行新版本的同一个安装器，无需删除旧版；已有科目、词条和练习记录会被保留。

> 目前支持 Apple 芯片 Mac（M1/M2/M3/M4 及后续型号）。由于应用未经 Apple 公证，首次打开如被拦截，请右键安装器并选择“打开”。
