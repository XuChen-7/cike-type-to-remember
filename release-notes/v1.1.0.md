# 键记 v1.1.0

首个公开本地版本，现已更新为“键记”。

## 主要功能

- 按科目和文件夹管理词条。
- 支持批量导入、编辑和批量删除。
- 支持词汇与释义组合的连续打字练习。
- 支持无限循环练习和释义默写。
- 默写时会清楚显示空格和标点；空格使用 `·` 提示，输入后同步变色。
- 支持回车提交答案，以及在结果出现后回车进入下一题。
- 统计正确率、平均速度和趋势。
- 同一个 ZIP 可自动判断全新安装或覆盖升级。
- 程序与本地数据分开保存；升级不会覆盖科目、词条、封面和练习记录，并会先自动备份。
- 支持所有当前 Apple Silicon Mac：M1–M5 系列，包括 Pro、Max 和 Ultra 机型。

## 安装或升级

解压 ZIP 后运行“安装键记.command”。首次被 macOS 拦截时，请右键它并选择“打开”。安装完成后使用桌面的“键记”网页快捷入口；已安装用户可直接覆盖升级，无需重新导入词条。
